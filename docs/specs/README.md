# Especificações de melhorias

Cada melhoria que passa pelo Analista (issue "Melhoria com especificação") ganha um arquivo `<nº-da-issue>-<slug>.md` aqui,
com objetivo, comportamento esperado, mudanças técnicas, fora do escopo, dúvidas e **critérios de aceite**.
É o equivalente, para a plataforma, do `RULES.md` de cada jogo: o Desenvolvedor implementa a partir dele, e o QA e o Revisor conferem contra ele.
Os arquivos ficam no repositório depois do merge como registro das decisões.
