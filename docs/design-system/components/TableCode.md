# TableCode

O código de 5 caracteres da mesa, para compartilhar com os amigos.

Classe: `room-code` (nome do app). No app: `Lobby.tsx`.

- Fredoka 28px, peso 700, espaçamento 0.2em, em `primary` (estilo `table-code`).
- Sempre ao lado de um botão "Copiar código" ou "Compartilhar", seguido de toast "Código copiado."
