# Toast

Aviso passageiro na base da tela, que some sozinho ou ao toque.

Classe: `toast`. No app fica `position: fixed` centralizado embaixo; aqui aparece no fluxo.

- Cor invertida: fundo `ink`, texto `bg`, sombra `shadow-float`.
- Frases curtas no passado: "Código copiado.", "Rita entrou na mesa."
