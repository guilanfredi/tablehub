# Badge

Selo curto em pílula para estado e papel do jogador.

Classes: `badge` + `badge-ok` (positivo: Pronto), `badge-warn` (atenção: regras mudaram), `badge-primary` (destaque: Sua vez, Dono). Sem variante, é neutro (Bot, Aguardando, nome do jogo).

- Texto em caixa-alta, 12px, peso 800 (`overline`). Uma ou duas palavras.
- A cor nunca carrega o significado sozinha: o texto diz o estado.
- Pílula `radius-full`, fundo "soft" da mesma cor do texto.
