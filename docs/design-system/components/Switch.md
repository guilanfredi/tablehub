# Switch

Interruptor liga/desliga para opções do jogo.

Classe: `switch` no `<label>`, com um `<input type="checkbox">` dentro e o texto ao lado. No app: `OptionsForm.tsx`.

- Ligado: trilho `primary`, bolinha `on-primary`. Desligado: `surface-raised` com borda `line-strong`.
- O texto descreve a opção ligada: "Mão de 11 às cegas".
