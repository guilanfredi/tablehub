# Scoreboard

Placar compacto com um chip por jogador.

Classes: `scoreboard` no contêiner, `score-chip` por jogador (com um `seat` pequeno dentro), `active` somado em quem está jogando agora.

- Pontos com números tabulares para não pular de largura.
- Ordem dos chips = ordem dos assentos, não a classificação.
