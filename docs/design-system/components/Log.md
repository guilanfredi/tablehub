# Log

Lista curta de mensagens, com a mais recente embaixo. O histórico da partida usa o painel comum
([History](History.md)); a classe `log` fica para listas pequenas dentro de um card.

Classe: `log` (coluna invertida, rola sozinho até 160px). Cada linha é um `<div>`; o nome do jogador vai em `<b>`.

- Texto 13px em `ink-muted`, nomes em `ink`.
- Frases curtas no passado: "Bia construiu uma estrada."
