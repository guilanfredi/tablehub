# Banner

Mensagem em faixa para erros, avisos e informações dentro da página.

Classes: `banner` (aviso ou erro, coral), `banner-info` somado (informação, âmbar), `conn-banner` (faixa fixa no topo quando a conexão cai).

- Erros dizem o que houve e o que fazer: "Mesa não encontrada. Confira o código."
- Use `role="alert"` para erros que aparecem depois de uma ação.
- O `conn-banner` fica `position: fixed` no topo no app; aqui aparece no fluxo.
